# Terraform - Level 4

## Overview
This level focuses on scaling Terraform for team and CI/CD workflows — reusable modules, pipeline integration, and code organization.

## Learning Objectives
* Configure alerting within CI/CD pipelines
* Use local variables to simplify configurations
* Build and consume reusable Terraform modules
* Manage CI/CD pipelines for infrastructure deployment
* Organize Terraform code using symlinks
