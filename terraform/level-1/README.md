# Terraform - Level 1

## Overview
This level focuses on foundational AWS resource provisioning using Terraform, covering core compute, storage, networking, and IAM building blocks.

## Learning Objectives
* Write and apply basic Terraform configurations to provision AWS resources
* Provision core compute resources (EC2, AMIs, EBS volumes and snapshots)
* Create foundational networking (VPC, security groups, Elastic IPs)
* Manage IAM users, groups, and policies with Terraform
* Work with Terraform input variables and resource lifecycles
