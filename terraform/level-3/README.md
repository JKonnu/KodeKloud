# Terraform - Level 3

## Overview
This level covers advanced, production-oriented Terraform architecture — multi-tier deployments, data pipelines, encryption, and environment isolation.

## Learning Objectives
* Design and deploy multi-tier AWS architectures with Terraform
* Build real-time data ingestion pipelines with Kinesis Firehose
* Enforce IAM naming standards and fine-grained access policies
* Implement encryption at rest with AWS KMS
* Manage environment isolation using Terraform workspaces
