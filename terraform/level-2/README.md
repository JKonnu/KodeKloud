# Terraform - Level 2

## Overview
This level builds on the fundamentals with intermediate Terraform workflows — private networking, resource lifecycle policies, and service-to-service integrations.

## Learning Objectives
* Deploy resources into private VPC subnets and manage multiple EC2 instances
* Implement S3 lifecycle and deletion-prevention policies
* Integrate SNS, SQS, Kinesis, and CloudWatch for event-driven workflows
* Attach IAM roles, inline policies, and Secrets Manager access via Terraform
* Combine Terraform with CloudFormation for resource provisioning
