# Azure Cloud - Level 1

## Overview
This level focuses on foundational Azure concepts — virtual machines, networking, storage, and basic resource management via console and CLI.

## Learning Objectives
* Create and manage Azure Virtual Machines and SSH access
* Configure Virtual Networks, subnets, and public IPs
* Attach managed disks, NICs, and configure NSGs
* Create and manage Blob Storage containers
* Deploy resources using ARM templates and the Azure CLI
