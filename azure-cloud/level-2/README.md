# Azure Cloud - Level 2

## Overview
This level builds intermediate Azure skills — networking configurations, container registries, and application hosting.

## Learning Objectives
* Configure user data and automate VM setup via CLI
* Deploy VMs into public and private virtual networks
* Work with Azure Container Registry and container synchronization
* Deploy and manage web applications
* Configure load balancers and virtual network peering
