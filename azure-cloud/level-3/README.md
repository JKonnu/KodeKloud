# Azure Cloud - Level 3

## Overview
This level covers advanced Azure services — managed databases, container platforms, and security services.

## Learning Objectives
* Manage storage lifecycle policies and Azure Table Storage
* Run containers and static websites on Azure VMs
* Manage secrets with Azure Key Vault
* Configure Application Gateway and Event Hub integrations
* Set up and manage Azure Kubernetes Service (AKS)
