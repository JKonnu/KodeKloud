# Docker - Level 1

## Overview
This level covers the fundamentals of installing Docker and managing basic containers.

## Learning Objectives
* Install Docker packages and start the Docker service
* Deploy and manage containers (Nginx)
* Copy files to and from containers
* Delete containers and troubleshoot container issues
