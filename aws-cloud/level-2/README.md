# AWS Cloud - Level 2

## Overview
This level builds intermediate AWS skills — application hosting, load balancing, serverless functions, and VPC networking.

## Learning Objectives
* Host applications on EC2 with Elastic IPs and Application Load Balancers
* Configure and troubleshoot RDS instances (public/private, snapshots)
* Build public and private VPCs with peering and NAT gateways
* Create Lambda functions via console and CLI
* Set up private ECR repositories and troubleshoot connectivity issues
