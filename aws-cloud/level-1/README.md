# AWS Cloud - Level 1

## Overview
This level focuses on foundational AWS concepts and services — compute, storage, IAM, and basic networking via the console and CLI.

## Learning Objectives
* Understand AWS global infrastructure and core services
* Deploy and manage EC2 instances, volumes, and AMIs
* Learn IAM fundamentals — users, groups, roles, and policies
* Work with S3 storage and RDS databases
* Understand basic VPC networking concepts
