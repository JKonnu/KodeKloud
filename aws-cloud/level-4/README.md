# AWS Cloud - Level 4

## Overview
This level focuses on production-grade, automated AWS architecture — scaling, CI/CD, and event-driven systems.

## Learning Objectives
* Implement Auto Scaling for high availability
* Automate CI/CD with AWS CodePipeline
* Build event-driven processing with S3 and Lambda
* Integrate SQS and SNS for reliable messaging
* Build and manage APIs with AWS API Gateway
