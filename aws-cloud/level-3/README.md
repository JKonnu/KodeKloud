# AWS Cloud - Level 3

## Overview
This level covers advanced AWS architecture — container orchestration, infrastructure as code, and managed databases.

## Learning Objectives
* Deploy and manage applications with load balancing on AWS
* Automate infrastructure deployment with CloudFormation
* Deploy containerized applications with Amazon ECS and EKS
* Secure data with AWS KMS
* Build and manage NoSQL databases with DynamoDB
