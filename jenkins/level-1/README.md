# Jenkins - Level 1

## Overview
This level covers the fundamentals of setting up and configuring a Jenkins server.

## Learning Objectives
* Install and configure a Jenkins server
* Install and manage Jenkins plugins
* Configure user access and permissions
* Organize jobs using folders
* Create a basic Jenkins job for package installation
