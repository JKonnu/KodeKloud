# Jenkins - Level 2

## Overview
This level introduces intermediate Jenkins job configuration and automation.

## Learning Objectives
* Create Jenkins views to organize jobs
* Configure parameterized builds
* Understand and manage Jenkins workspaces
* Create a database backup job
* Schedule Jenkins jobs to run automatically
