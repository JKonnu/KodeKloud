# Jenkins - Level 3

## Overview
This level focuses on scaling Jenkins with distributed builds and pipeline-as-code.

## Learning Objectives
* Configure Jenkins slave/agent nodes
* Secure Jenkins projects and permissions
* Build Docker images from Jenkins
* Create deployment pipelines
* Implement conditional pipeline logic
