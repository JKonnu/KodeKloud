# Jenkins - Level 4

## Overview
This level covers advanced Jenkins CI/CD pipeline design for real-world application delivery.

## Learning Objectives
* Create deployment jobs and chained build pipelines
* Configure merge-request (MR) triggered jobs
* Build multistage pipelines
* Set up and deploy a Node.js application through Jenkins
