# Git - Level 3

## Overview
This level covers intermediate-to-advanced Git operations for managing history and pull requests.

## Learning Objectives
* Cherry-pick commits between branches
* Manage and review pull requests
* Perform hard resets and clean untracked files
* Use Git stash to manage in-progress work
