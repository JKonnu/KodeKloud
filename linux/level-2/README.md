# Linux - Level 2

## Overview
This level introduces intermediate Linux administration — automation with cron and scripts, service configuration, and troubleshooting common issues.

## Learning Objectives
* Automate tasks with cron jobs and bash scripts
* Configure services such as Postfix, HAProxy, and MariaDB
* Troubleshoot DNS, Apache, and mail server issues
* Manage sudo access, local repositories, and firewalld rules
* Apply GPG encryption and log rotation
