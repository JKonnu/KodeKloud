# Linux - Level 4

## Overview
This level focuses on full-stack application deployment on Linux — load balancing, databases, and PHP application hosting.

## Learning Objectives
* Install and configure Nginx as a load balancer
* Install and configure PostgreSQL and general database servers
* Write conditional bash scripts
* Deploy and configure PHP-FPM with Nginx
* Deploy a complete web application stack
