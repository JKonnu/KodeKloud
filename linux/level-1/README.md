# Linux - Level 1

## Overview
This level focuses on foundational Linux system administration — user and group management, permissions, and basic system security.

## Learning Objectives
* Create and manage users, groups, and service accounts
* Configure secure SSH access and restrict root login
* Set file and script permissions and correct permission issues
* Install and configure SELinux
* Configure timezones, firewalls, and process limits
