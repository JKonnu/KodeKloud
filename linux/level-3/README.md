# Linux - Level 3

## Overview
This level covers advanced web and application server configuration on Linux — reverse proxies, SSL, and access control.

## Learning Objectives
* Configure Apache redirects and protected directories
* Install and configure SFTP and Tomcat servers
* Set up Nginx as a reverse proxy and configure IPtables
* Troubleshoot Linux processes and network services
* Apply PAM authentication and SSL for Nginx
