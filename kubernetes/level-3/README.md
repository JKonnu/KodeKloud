# Kubernetes - Level 3

## Overview
This level focuses on advanced Kubernetes workloads — persistent storage, secrets management, and real application deployments.

## Learning Objectives
* Configure init containers and persistent volumes
* Manage secrets securely within Kubernetes
* Deploy LAMP and LEMP stacks
* Deploy and troubleshoot real-world applications (Iron Gallery, Python apps)
* Perform general Kubernetes troubleshooting
