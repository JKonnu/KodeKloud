# Kubernetes - Level 1

## Overview
This level covers foundational Kubernetes concepts — pods, deployments, namespaces, and basic workload management.

## Learning Objectives
* Deploy and manage pods, deployments, and replicasets
* Set resource limits and namespaces for workloads
* Perform rolling updates and rollbacks
* Schedule cronjobs and jobs in Kubernetes
* Expose applications using NodePort services
