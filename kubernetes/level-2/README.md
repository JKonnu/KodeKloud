# Kubernetes - Level 2

## Overview
This level builds intermediate Kubernetes skills — multi-container pod patterns, application deployments, and troubleshooting.

## Learning Objectives
* Configure shared volumes and sidecar container patterns
* Deploy web servers and applications (Nginx, Jenkins, Grafana, Tomcat, Node.js)
* Manage environment variables in pods
* Troubleshoot deployment issues
* Deploy and fix a LAMP environment
